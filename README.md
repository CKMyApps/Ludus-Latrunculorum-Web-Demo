# Ludus Latrunculorum Web Demo

A single match against the computer. The demo stores its move history in this
browser's local storage so the player can continue or view the final result.
Clearing site data or using a different browser profile starts a fresh demo.

## GitHub Pages

1. Extract the ZIP and upload its contents to the repository root. Keep
   `index.html`, `manifest.webmanifest` and `icons/` in their original locations.
2. In repository **Settings → Pages**, choose **Deploy from a branch**.
3. Select **main** and **/ (root)**, then save.

The site is buildless. It uses relative paths so it also works at a project URL
such as `https://ckmyapps.github.io/latrunculi-demo/`.
